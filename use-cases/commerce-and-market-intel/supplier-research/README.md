# Supplier Marketplace Product Search - Supplier Intelligence Agent Demo

A reference workflow showing how a marketplace **Product Search** agent can use **Browserbase** to browse public sources for supplier intelligence.

## What This Demo Does

An SMB asks Product Search: *"Find me a verified Bluetooth speaker supplier from China. Check their compliance and estimate my landed costs."*

The agent then browses **4 different websites** in a single automated workflow:

| Step | Website | What It Does |
|------|---------|-------------|
| 1 | **supplier data portal** (US Customs data) | Discovers Chinese suppliers with proven US export track records |
| 2 | **Google Maps** | Physically verifies the factory location, reviews, and operating status |
| 3 | **CPSC Recalls** (US Product Safety) | Checks for recalled bluetooth speakers manufactured in China |
| 4 | **USITC HTS** | Looks up tariff rates and estimates landed costs |

## Capabilities

- **Cross-site agent**: Product Search operates across ANY website, not just Supplier Marketplace's ecosystem
- **Structured extraction**: Every site produces clean, typed data via Stagehand's `extract()` with Zod schemas
- **Verified + proxy**: Browserbase handles anti-bot protection automatically
- **Resilient**: Each step is independent — if one site is slow, the rest continue

## Setup

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

```bash
cp .env.example .env
```

Then edit `.env` with your actual keys:

- `BROWSERBASE_API_KEY` — from [browserbase.com/overview](https://browserbase.com/overview)
- `OPENAI_API_KEY` — from [platform.openai.com/api-keys](https://platform.openai.com/api-keys)

### 3. Run the demo

```bash
npm run demo
```

Or directly:

```bash
npx tsx supplier_marketplace-product_search-demo.ts
```

## Troubleshooting

**Demo crashes on a specific step**: Each step has its own try/catch, so individual failures should not crash the whole demo. If the entire script fails, check your environment variables.

**supplier data portal returns no results**: The site may rate-limit or change its layout. The demo continues regardless.

**HTS extraction fails**: The USITC tariff site has very large pages that can exceed the AI model's context window. The step still navigates and searches correctly — the hardcoded landed cost estimate is shown as a fallback.

**Stagehand extract returns empty data**: The underlying websites may have changed their HTML structure. Stagehand's AI-powered extraction adapts well, but major redesigns may require prompt adjustments.

## Customizing the Demo

- **Change the product**: Edit the search queries (e.g., replace "bluetooth speaker" with "solar panel" or "electric scooter")
- **Change the supplier region**: Edit "shenzhen" in the supplier data portal URL to another city
- **Add more steps**: The pattern is simple — navigate, wait, extract with a Zod schema
- **Use a different model**: Pass `model: "anthropic/claude-sonnet-4-5"` in the Stagehand constructor
