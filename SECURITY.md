# Security policy

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed
credential. Report it privately through
[Browserbase's security page](https://www.browserbase.com/security) and include
the affected recipe, steps to reproduce, and potential impact.

We will acknowledge the report, investigate it, and coordinate disclosure when
appropriate. Do not access data or accounts that you do not own while testing.

## Supported versions

Security fixes are applied to the latest version on the default branch. The
cookbook contains examples rather than a deployed service; individual recipes
may depend on third-party sites and packages with separate support policies.
