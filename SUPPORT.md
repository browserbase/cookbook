# Support

Use the right channel so requests reach the right team:

- Ask cookbook usage questions by opening a GitHub issue with the relevant
  recipe path and environment details.
- Report a reproducible recipe bug with the bug issue form.
- Request a new recipe with the recipe request form.
- Contact [Browserbase support](https://www.browserbase.com/contact) for account,
  billing, quota, or production service issues.

Include the recipe path, runtime and package-manager versions, exact command,
and a redacted error message. Never post API keys, cookies, session URLs, or
customer data.
