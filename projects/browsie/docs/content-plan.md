# Content plan

Browsie is both a product and a teaching project. Each release must include an artifact that explains
the design with a working example.

## First series

1. Build one persistent Stagehand browser inside an Eve session.
2. Put system prompts, tools, and skills in the correct layers.
3. Build a form skill that stops before Submit.
4. Add a Browserbase Context for a signed-in site.
5. Add a vault without putting secrets in the model prompt.
6. Expose the same three tools to Codex or Claude Code through MCP.
7. Read a redacted run trace and fix a failed browser task.

Each article will include a short video, a runnable branch, the prompt and skill files, and one test.
