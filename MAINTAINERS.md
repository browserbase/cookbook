# Maintainers

The Browserbase Developer Experience team maintains this cookbook.

Repository ownership and required reviews are defined in
[`.github/CODEOWNERS`](.github/CODEOWNERS). Browserbase employees should update
that file when team ownership changes. External contributors can use the
channels in [SUPPORT.md](SUPPORT.md).

Maintainers review recipe correctness, source provenance, publication
boundaries, dependency updates, and verification evidence. A passing install or
typecheck must not be described as a live workflow test.
